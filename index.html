Designing for the Usage Gap: A Zero-Backend Offline-First Architecture and a Convergent Event-Log Protocol for Learning in Low-Connectivity Settings

Rev. Dr. Chris Johnson

Abstract

Learning software and learning analytics usually assume reliable connectivity, yet in Nigeria about 140 million people lived within mobile broadband coverage but did not use mobile internet in 2025 (GSMA, 2026). This paper presents a design science study of two artifacts for learning in such settings: a zero-backend, offline-first progressive web app architecture, and the Convergent Learner Event Log (CLEL), a transport-agnostic protocol for merging learner event records produced on devices that stay offline for long periods. A recent systematic review found no study that formally specified a conflict-resolution protocol for learning analytics event logs under zero connectivity (Febrianty et al., 2026). CLEL addresses that gap by treating the event log as a grow-only set whose derived learner state is a deterministic function of the set. The paper states convergence, idempotence, and no-loss properties and tests them in 3,840 randomized simulation trials with partitions, message loss, duplication, and reordering, and in 20,000 randomized property checks. CLEL converged in every trial without losing a recorded event, whereas a snapshot last-write-wins baseline lost learner attempts in 3,558 of 3,840 trials. An emulated-device benchmark shows that the reference application shell is 12.9 KB compressed, becomes interactive in about 2.1 seconds on an emulated slow 3G connection with a sixfold CPU slowdown, and reloads and opens deep links offline in all test loads. No human participants were involved. The paper closes with a registered protocol for a field evaluation with Nigerian learners, which has not yet been conducted.

Keywords: offline-first, progressive web apps, learning analytics, conflict-free replicated data types, digital inclusion, Nigeria
